# Архитектурные решения (ADR) — «Пульс команды»

Формат имени файла: `NNNN-kebab-name.md`. Разделы ADR: «Статус», «Контекст», «Решение», «Рассмотренные альтернативы», «Последствия». Новое решение, отменяющее старое, оформляется новым ADR со ссылкой на старый; старый получает статус «Заменено ADR-NNNN».

Источники: ТЗ `.claude/TZ/TZ_Puls_komandy.md`, backlog `docs/product/backlog.md`, правила `.claude/CLAUDE.md`. Вопросы юристу — `docs/legal-questions.md`. Мелкие решения без согласования с заказчиком — `docs/decisions.md`.

Заказчику задаются вопросы только по архитектуре и выбору технологий, ПДн, безопасности и юридическим рискам, деньгам, срокам и объёму релиза, а также по прямым противоречиям в ТЗ, которые меняют поведение для пользователя. Остальное решаем сами и записываем в `docs/decisions.md`.
