| № | Вопрос | Итоговое решение | ADR |

| В-01 | REST API для кабинета | Не делаем: кабинет на Inertia, `/api/v1` только для каналов ответа | 0001, 0008 |
| В-02 | Строгость анонимности | **Снят:** анонимности нет вообще. Все ответы и комментарии подписаны; G-04, G-05, G-06, G-26, Q-15 закрыты. Сознательное отступление от ТЗ п. 6.5 | 0003, 0004, 0005, 0008 |
| В-03 | Хранение кода приглашения | HMAC для поиска + зашифрованная копия для показа, ключи в env | 0004, 0007 |
| В-04 | AI-сводки (R2) | Текст с псевдонимами, словарь на `membership_id`, имена подставляются при показе | 0004, 0005 |
| В-05 | Данные при удалении проекта и аккаунта | Физическое удаление сразу. Мягкого удаления, `deleted_at` и команд ручной очистки нет | 0001, 0002, 0004, 0005, 0008 |
| В-06 | Новая версия согласия | `consent_required`; до принятия API отклоняет приём ответов | 0003, 0005 |
| В-07 | On-premise | Не входит в R1; позже — поле «адрес сервера» (`optional_host_permissions`). Конфигурация через env | 0001, 0003, 0007, 0008 |
| В-08 | Яндекс Браузер | Устанавливается из Chrome Web Store | 0003 |
| В-09 | Сроки сессии и токенов | Сессия 14 дней (`SESSION_LIFETIME`, env). Без условия бездействия и без своего middleware. Токены бессрочные до отзыва. Удаление проекта подтверждается кодом из письма | 0002, 0003, 0007 |
| В-10 | Redis | Redis 8; лицензия при будущей поставке клиентам — риск Р-10 | 0002, 0007, 0008 |
| В-11 | Согласие после удаления аккаунта | Минимальная запись: дата, версия, ID без ПДн. Вопрос юристу ЮВ-2 | 0004, 0005 |
| В-12 | Расположение `new_types.md` | `docs/new_types.md` | 0001, 0006 |
| В-13 | Пограничные случаи дня | День открывается при создании проекта (если день рабочий); одобренный днём участник отвечает в тот же день; ответ принимается до 00:00 | 0004 |
| В-14 | Профиль сотрудника | Общая страница профиля, доступна без ролей в кабинете | 0001, 0003, 0005 |
| В-15 | Исключение с удалением ответов | Физическое удаление сразу | 0001, 0004, 0005 |
| В-16 | Сессия 24 ч / 14 дней против ТЗ п. 4.4 | **Снят:** сессия просто 14 дней; backlog F-005 обновлён | 0002, 0003 |
| В-17 | Словарь псевдонимов при исключении | Запись удаляется при любом исключении (и при удалении аккаунта). В старых сводках псевдоним без записи показывается как есть («Участник 3») | 0004, 0005 |
| В-18 | Порог анонимности по порядку ответов | **Снят** вместе с анонимностью | 0005 |
| В-19 | Журнал действий при удалении | Записи, связанные с удалённым пользователем (автор или объект) или проектом, удаляются целиком | 0001, 0004, 0005, 0008 |
