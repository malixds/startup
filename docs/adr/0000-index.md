## Закрытые вопросы (ответы заказчика от 2026-10-27)

| № | Вопрос | Итоговое решение | Совпало с рекомендацией | ADR |
| --- | --- | --- | --- | --- |
| В-01 | REST API для кабинета | Не делаем: кабинет на Inertia, `/api/v1` только для каналов ответа | Да | 0001, 0008 |
| В-02 | Строгость анонимности | Вариант B: показ после закрытия дня. Не больше одного анонимного комментария на участника в день. Порог «< 3» считается **по фактически ответившим за день** (в момент отправки, включая автора) | Частично: порог по ответившим, а не по ожидаемым | 0004, 0005, 0008 |
| В-03 | Хранение кода приглашения | HMAC для поиска + зашифрованная копия для показа; ключи HMAC и шифрования задаются в env | Да | 0004, 0007, 0008 |
| В-04 | AI-сводки (R2) | Текст с псевдонимами, словарь привязан к `membership_id`; при удалении участника его запись в словаре удаляется | Да, с уточнением про удаление записи словаря | 0001, 0004, 0005 |
| В-05 | Данные при удалении проекта и аккаунта | Мягкое удаление (`deleted_at` у `users`, `projects`, `responses`), физическое — вручную; журнал хранится 1 год. **Вопрос юристу ЮВ-1** | Нет: рекомендовалось физическое удаление | 0001, 0002, 0004, 0005, 0007, 0008 |
| В-06 | Новая версия согласия | `consent_required`; пока согласие не принято, API отклоняет приём ответов и анонимных комментариев | Да | 0003, 0005 |
| В-07 | Расширение для on-premise | On-premise в R1 не входит; позже — поле «адрес сервера» (`optional_host_permissions`). Принцип «вся конфигурация через env» сохраняется | Частично: on-premise убран из R1 | 0001, 0003, 0007, 0008 |
| В-08 | Яндекс Браузер | Устанавливается из Chrome Web Store | Да | 0003, 0008 |
| В-09 | Сроки сессии и токенов | Сессия — 14 дней абсолютно + выход после 24 ч бездействия, оба срока в env. Токены устройств бессрочные до отзыва. Удаление проекта подтверждается кодом из письма | Нет: рекомендовалась сессия 30 дней | 0002, 0003, 0007, 0008 |
| В-10 | Redis | Redis 8. Лицензия при будущей поставке клиентам — риск, без смены продукта | Да | 0002, 0007, 0008 |
| В-11 | Согласие после удаления аккаунта | Остаётся минимальная запись: дата, версия, ID без ПДн. **Вопрос юристу ЮВ-2** | Нет: рекомендовалось удалять | 0004, 0005, 0008 |
| В-12 | Расположение `new_types.md` | `docs/new_types.md` | Да | 0001, 0006 |
| В-13 | Пограничные случаи дня | День открывается сразу при создании проекта (если день рабочий); одобренный днём участник отвечает в тот же день; ответ принимается до 00:00 следующего локального дня | Да | 0004 |
| В-14 | Профиль сотрудника | Общая страница профиля, доступна сотруднику без ролей в кабинете | Да | 0001, 0003, 0005 |
