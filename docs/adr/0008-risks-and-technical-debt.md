# ADR-0008. Риски, технический долг релиза 1 и порядок реализации

**Статус:** Принято
**Дата:** 2026-10-27
**Связано:** ADR-0001–0007; backlog раздел 4 (зависимости), раздел 5 (G-01–G-30), раздел 6 (Q-10–Q-32); решения заказчика В-01–В-19; `docs/legal-questions.md`

## Контекст

R1 — рабочий пилот на Chromium и `/survey`. Дизайна, текстов ПДн, домена и хостинга пока нет. On-premise в R1 нет (В-07), анонимности нет (ADR-0005). ПДн удаляются физически и сразу, вместе со связанными записями журнала (В-05, В-19). Здесь записано, на что мы сознательно идём и в каком порядке строим.

## Решение

### Риски

Номера рисков сохранены, чтобы не ломать ссылки. Снятые риски отмечены.

| # | Риск | Вероятность / влияние | Мера |
| --- | --- | --- | --- |
| Р-1 | Без анонимного канала сотрудники отвечают менее откровенно. Сознательное отступление от ТЗ п. 6.5 | Средняя / среднее | Решение заказчика. На пилоте следить за заполненностью комментариев и открытых вопросов; вернуть анонимность — отдельным ADR |
| Р-2 | Ошибки часовых поясов и границ дня | Высокая / высокое | Единый сервис времени проекта, unit-тесты, правила В-13, «ленивое» открытие дня |
| Р-3 | Сбой Scheduler или воркера | Средняя / высокое | Идемпотентное открытие дня по запросу, `/health`, отдельный супервизор `mail` |
| Р-4 | Эрозия границ модулей | Высокая / среднее | deptrac или arch-тест в CI |
| Р-5 | Утечка ключа шифрования раскрывает коды приглашения | Низкая / низкое | Код сам по себе доступа не даёт; ключи отдельно от `APP_KEY`; перевыпуск кодов |
| Р-6 | Расширение работает только с одним доменом | Определено / низкое в R1 | Поле «адрес сервера» — после R1 |
| Р-7 | Модерация магазинов затягивает публикацию | Средняя / среднее | Минимальные разрешения; `/survey` как запасной канал |

| Р-9 | Особенности Firefox MV3 и Safari | Определено / низкое | Правила ADR-0003 |
| Р-10 | Лицензия Redis 8 при будущей поставке клиентам | Низкая в R1 / среднее после | Проверить перед первой поставкой |
| Р-11 | Horizon работает только с Redis | Низкая / низкое | Бизнес-код не зависит от драйвера |
| Р-12 | Перебор 6-значных кодов | Низкая / высокое | HMAC, 5 попыток, лимиты |

| Р-14 | Удалённые данные остаются в бэкапах до 14 дней | Определено / среднее | Вопрос юристу ЮВ-3 |

| Р-18 | ~~Мягкое удаление против права субъекта~~ | Снят: удаление физическое | — |
| Р-19 | ~~Повторная регистрация при мягко удалённом email~~ | Снят | — |
| Р-20 | ~~Асимметрия словаря и мягкого удаления~~ | Снят | — |

### Сознательный технический долг R1

| Долг | Почему приемлемо | Когда вернуть |
| --- | --- | --- |
| Кабинет на Inertia без REST (В-01) | Сервисы канал-независимы | При мобильном приложении кабинета |
| Изоляция проектов без RLS | Policy + scope + тесты | При многоарендной продаже |
| Polling вместо WebSocket | Задачи редкие | С realtime-алертами |
| Флаги функций без UI | Один флаг | С тарифами |
| Календарь только по дням недели | F-027 отложен | С F-027 |
| Внешние метрики — только контракт | Трекеры не в пилоте | С интеграциями |
| Типы API на клиенте пишутся вручную | API небольшой | При расхождениях |
| Экспорты на локальном диске | Один сервер | При нескольких узлах |
| Нет e2e-тестов расширения | Ручной чек-лист | После стабилизации |
| Расширение с одним доменом | On-premise вне R1 | Перед установкой у клиента |
| Заглушки текстов | Q-08 | По мере поставки |
| Нет prod-compose, бэкапов, мониторинга | Q-07 | При выборе хостинга |

### Порядок реализации R1

Каждый шаг — законченный PR с тестами и обновлённым OpenAPI. Новые типы описываются в `docs/new_types.md` (В-12).

1. **Фундамент.** Монорепо, compose (Redis 8), Laravel, каркас модулей, Horizon, Scheduler, CI, `/health`. (F-064, F-065, F-067, F-069, F-070, F-071)
2. **Identity + Notifications.** Вход по коду, письма, сессии на 14 дней, токены устройств, страница профиля, согласие и `consent_required`. (F-001–F-005, F-068)
3. **Projects + Audit.** Проект, роли, Policies, код приглашения, заявки, флаг участия, передача владения, исключение, удаление проекта (код из письма, физическое, вместе с журналом), флаги, журнал. (F-007–F-011, F-013–F-018, F-059, F-061, F-077)
4. **Survey.** (F-019–F-026, F-028, F-029)
5. **Responses + общий пакет формы.** Ответ с подписанным комментарием, `/survey`. (F-031–F-033, F-037, F-038, F-062)
6. **Расширение для Chromium.** (F-034–F-036, F-039)
7. **Analytics.** (F-040–F-049, F-051)
8. **Права субъекта и завершение.** Выгрузка; физическое удаление аккаунта через `PersonalDataLifecycle`, включая записи журнала, с тестом полноты (Р-22); сидер; замеры; документация. (F-006, F-072, F-073, F-074)

## Рассмотренные альтернативы

1. **Ждать ответов на все вопросы.** Отклонено.
2. **Сразу закрыть долг.** Отклонено.

## Последствия

- Долг пересматривается при планировании R2.
- Ответы на В-20, ЮВ-2 и ЮВ-3 меняют сервисы, а не схему.
